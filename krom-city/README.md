# KROM DIGITAL // Fondo Futurista

Fondo web 3D (ciudad cyberpunk roja con branding Krom) para celular y pantallas grandes.

## Usar
1. Abre la carpeta en VS Code y ejecuta con Live Server (o abre `index.html`).
2. Para publicar: sube la carpeta a un repo de GitHub y activa GitHub Pages (rama main).

## Controles
- `F` o boton ⛶: pantalla completa
- `H` o doble toque/clic: ocultar la interfaz
- Celular: se mueve con el giroscopio

## Archivos
- `index.html`: estructura y HUD
- `styles.css`: estilos (vertical y horizontal)
- `app.js`: reloj, escena 3D (Three.js r128 desde cdnjs), lluvia y letreros
